---
name: brain
description: The vault's toolbox. Use it for questions about the vault, such as its status, dates, lookups and counts, and for questions about why the system works as it does.
---

Run the toolbox from the vault's top folder:

    uv run .agents/skills/brain/scripts/brain.py <command>

The commands come in a later version, so there is nothing to run yet. Say so when a question needs a command. Do not guess dates, lookups or counts.

For questions about the vault, follow "Answering questions" in the vault's `AGENTS.md`.

For the reasons behind a routine, read `.agents/skills/brain/references/system-design.md`. It never overrides `99 System/rules.md` or `99 System/config.md`.
